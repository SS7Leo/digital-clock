# Digital Clock Project

This repository contains the code for a digital clock built using React. The clock displays the current time dynamically and updates every second. It includes a 12-hour format with AM/PM indicators, styled for a clean and modern user interface.

---

## 🛠 Features

- **Real-time Updates**: The clock updates every second.
- **12-hour Format**: Displays time in 12-hour format with AM/PM.
- **Dynamic Styling**: Fully styled components using modern CSS techniques.
- **Lightweight and Responsive**: Works seamlessly on desktop and mobile browsers.

---

## 🚀 Technologies Used

- **React**: JavaScript library for building user interfaces.
- **CSS**: For styling and layout design.

## 🔧 Setup and Installation

Follow these steps to run the project locally:

1. Clone the repository:
   
     "git clone https://github.com/SS7Leo/digital-clock.git"
   
2. Navigate to the project directory:

     "cd digital-clock"

3. Install dependencies:

     "npm install" or "npm i"

4. Start the development server:

     "npm start"

5. Open your browser and visit:

     http://localhost:3000
